Mapa de instrumentos de apoyo empresarial · UNE
================================================

mapa-instrumentos-uruguay.html
  El sitio completo en un solo archivo. Se abre con doble clic en cualquier navegador.

Clasificacion_etapas_B20_revisada_bases.xlsx
  Excel de insumos con palabras clave, revisión con bases (ajustes resaltados con
  comentario y cita), fuentes a corregir, y montos y cofinanciamiento detectados.

proyecto-fuente.zip
  Código del sitio (React + Vite + Framer Motion), datos y scripts:
    npm install            instala dependencias
    npm run dev            sitio en modo desarrollo
    npm run build          sitio estático en dist/
    npm run build:single   un solo HTML en dist-single/
  Actualizar datos:
    python3 scripts/extraer_bases.py data-fuente/Clasificacion_etapas_B20_ajustada.xlsx
    python3 scripts/revisar_clasificacion.py
    python3 scripts/aplicar_revision_excel.py
    npm run data
  Detalle en README.md dentro del proyecto.
